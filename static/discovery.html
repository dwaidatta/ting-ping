## network_discovery

Sweeps an IPv4 subnet and lists every host that answers, with its hostname (when it resolves) and round-trip time. Nothing is persisted — run it again whenever the network changes.

## port_scan

Probes one host across a set of TCP ports and reports which answer. Point it at any IPv4 or IPv6 address — on your own network or beyond it.
