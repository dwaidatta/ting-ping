## device_status

Read from this machine’s own network stack — ipconfig, the adapter counters and live probes. Loads automatically when the page opens; refresh device re-reads it on demand. The public-identity block is the one part that leaves your network: it asks an external service how your address looks from outside. Set TP_PUBLIC_IP_LOOKUP=0 to switch that off.

## monitors

One polling loop per host. Results are held in memory only — latency history and uptime reset when the server restarts.
